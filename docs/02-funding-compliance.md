# 敏之诗资助期限与合规执行手册

本文是敏之诗第一阶段的小额资助合规手册，用于把“想帮助人”变成可执行、可留痕、可暂停、可复盘的工作流程。

重要说明：本文是项目执行规则和协议草案，不构成正式法律意见。具体个案如涉及较大金额、外部资金、税务争议、跨境支付、未成年人、疾病隐私、债务纠纷或公开传播争议，应先咨询中国执业律师和财税专业人士。

## 一、基本法律定位

第一阶段建议定位为：发起人以个人合法收入向特定自然人提供小额、无偿、非对价性质的生活支持。

执行上应坚持以下边界：

1. 不是公开募捐：不面向社会收款，不代收公众捐赠，不组织众筹。
2. 不是慈善组织：不使用容易使公众误认为已登记公益组织、基金会或慈善组织的表述。
3. 不是劳动或委托：受资助人不因收款而承担工作、宣传、创作、投稿、站台、推广等义务。
4. 不是投资或借贷：资助款不需要返还，不产生利息、收益、分红、版权或其他经济权益。
5. 不是版权交易：资助不换取诗歌作品、著作权、署名权、发表权、授权使用权或优先合作权。
6. 不是医疗、社工或危机干预服务：项目只做小额资金支持和有限信息记录，不承诺专业救助。

## 二、资助期限规则

第一阶段采用“半年一签”。

1. 单期资助期限一般为 6 个月。
2. 标准金额为每月 300 元人民币。
3. 每月原则上固定日期支付，建议写入协议。
4. 单期到期自然结束，不自动续期。
5. 续签应重新确认四件事：发起人预算、受资助人意愿、申请资格、项目合规能力。
6. 续签最多仍按单期处理，不形成长期供养、固定工资或连续雇佣关系。
7. 若项目资金能力变化，可以在提前通知后不续签；如需提前终止，应按协议执行。

建议公开口径：

> 敏之诗第一阶段采取半年一签的小额支持方式，每期一般为 6 个月，每月 300 元。期满自然结束；如双方愿意且项目预算允许，可重新评估是否续签。

## 三、资助前流程

每一位受资助人进入正式支持前，至少完成以下步骤：

1. 申请人本人自愿提交申请或明确接受项目联系。
2. 核验其诗歌发表记录或可信公开作品记录。
3. 收集最小必要困难说明，不要求羞辱式证明。
4. 告知项目边界：金额有限、半年一签、无公众募捐、无附带义务、保护隐私。
5. 确认是否匿名公开，默认匿名。
6. 签署《诗人小额支持协议》。
7. 建立内部记录编号，不在公开文件中暴露身份证件、手机号、银行卡、住址等敏感信息。

不得在协议签署前做的事：

1. 公开申请人姓名或困境细节。
2. 要求申请人发布感谢内容。
3. 暗示资助与作品、宣传、社媒互动或商业合作有关。
4. 让第三方围观、评判、转发申请人的敏感材料。

## 四、资助中流程

每月支付时保留内部记录：

1. 资助编号。
2. 支付日期。
3. 支付金额。
4. 支付方式。
5. 当期协议编号或签署日期。
6. 是否已完成支付。
7. 是否发生暂停、延期、调整或异常。

每月公开时只公开必要信息：

1. 当月资助人数。
2. 当月总支出。
3. 年度累计支出。
4. 匿名案例编号。
5. 规则变化或执行问题。

不公开：

1. 收款账户。
2. 身份证件。
3. 聊天截图。
4. 协议签署版全文。
5. 详细困难叙事。
6. 未经同意的作品链接、城市、职业或笔名。

## 五、资助到期与续签

到期前 15 日内，完成一次轻量复核：

1. 发起人是否仍有预算。
2. 受资助人是否愿意继续。
3. 项目是否存在合规、隐私或沟通风险。
4. 是否已有其他更合适的申请人等待。
5. 是否需要调整规则或暂停扩张。

处理结果只能有三类：

1. 到期结束：正常结束，不需要说明私人原因。
2. 续签一期：重新签署或补充确认，不默认延续。
3. 暂缓决定：信息不足或预算不足时，先暂停承诺。

公开口径应避免“淘汰”“不够困难”“不再值得”等表达。

## 六、协议要点

协议必须覆盖以下要点：

1. 双方身份：发起人作为个人资助方，受资助人作为自然人接受方。
2. 资助性质：小额、无偿、非对价、非借贷、非投资。
3. 资助期限：一般 6 个月，起止日期明确。
4. 资助金额：每月金额、支付时间、支付方式。
5. 无附带义务：不要求宣传、感谢、写作、投稿、授权、站台。
6. 无经济利益：不产生版权、收益、分红、佣金、雇佣、委托、代理、合作等权益。
7. 资金来源：资助方确认资金来源合法合规。
8. 资金使用：受资助人自主决定用途，并自行承担合法合规责任。
9. 隐私保护：申请材料和签署信息仅用于项目履行和必要记录。
10. 公开授权：默认匿名；任何实名、笔名、作品链接公开都需单独同意。
11. 暂停终止：预算不足、信息不实、重大风险、不可抗力或双方协商一致时可暂停或终止。
12. 争议处理：先友好协商，协商不成按协议约定处理。

## 七、个人信息合规清单

收集前必须告知：

1. 收集目的：申请判断、协议履行、支付记录、项目复盘。
2. 收集范围：姓名或笔名、联系方式、发表记录、困难说明、收款信息。
3. 使用方式：内部核验、支付、匿名统计。
4. 保存期限：第一阶段建议协议结束后 3 年内保存必要记录，期满删除非必要敏感材料。
5. 公开规则：默认匿名，公开前另行征得同意。
6. 撤回方式：申请人可以撤回公开授权或要求删除非必要材料。

敏感信息处理原则：

1. 能不收就不收。
2. 能看不存就不存。
3. 能打码就打码。
4. 能匿名就匿名。
5. 能内部留存就不公开。

## 八、终止或暂停情形

项目可以暂停或终止单期资助的情形：

1. 发起人个人预算不足。
2. 受资助人主动要求停止。
3. 双方无法继续保持基本联系。
4. 发现申请信息存在重大不实。
5. 继续资助可能导致隐私、名誉、合规或人身安全风险。
6. 发生政策、平台规则、支付渠道或不可抗力变化。
7. 双方协商一致。

终止时应做三件事：

1. 私下告知对方。
2. 内部记录原因。
3. 公开记录仅写可公开部分，不扩大披露。

## 九、资料保存

GitHub 只保存公开规则、模板、匿名记录和工作流程。

不得提交到 GitHub：

1. 身份证件。
2. 手机号、地址、银行卡。
3. 签署后的协议原件。
4. 未打码转账凭证。
5. 聊天记录。
6. 困难证明原件。
7. 任何能够直接识别申请人的敏感材料。

建议本地建立加密资料夹，按编号保存：

1. 协议签署版。
2. 转账凭证。
3. 最小必要核验材料。
4. 对方公开授权记录。

## 十、公开说明模板

用于社媒、README 或月报：

> 敏之诗目前是个人小额支持尝试，不是公开募捐项目，暂不接受公众捐款。第一阶段每位受资助人原则上半年一签，每月 300 元。资助不附带宣传、创作、版权、商业合作或其他义务。项目会公开规则、流程和匿名化资金记录，但不会公开申请人的敏感隐私。

## 十一、下一步合规任务

1. 用协议模板完成第一位受资助人的签署流程。
2. 建立内部编号规则，例如 `MZS-2026-001`。
3. 建立非公开资料夹并加密保存签署版协议和转账凭证。
4. 制作月度匿名支出记录模板。
5. 在任何公开申请入口上线前，再做一次隐私和措辞检查。

## 十二、参考依据

以下依据用于支持本手册的基本边界，实际执行仍应结合具体事实咨询专业人士：

1. 《中华人民共和国民法典》合同编赠与合同规则：赠与合同是赠与人将自己的财产无偿给予受赠人、受赠人表示接受赠与的合同。参考最高人民检察院公开版本：https://www.spp.gov.cn/spp/ssmfdyflvdtpgz/202008/t20200831_478413.shtml
2. 《中华人民共和国个人信息保护法》：个人信息处理应遵循合法、正当、必要和诚信原则，并限于处理目的的最小范围。参考中央网信办公开版本：https://www.cac.gov.cn/2021-08/20/c_1631050028355286.htm
3. 《慈善组织公开募捐管理办法》：依法取得公开募捐资格的慈善组织可以面向公众开展募捐；不具有公开募捐资格的组织和个人不得自行开展公开募捐。参考司法部公开版本：https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202504/t20250428_518212.html
4. 《慈善法》修订相关公开说明：不具有公开募捐资格的组织或个人基于慈善目的与具有公开募捐资格的慈善组织合作时，合作方不得以任何形式自行开展公开募捐。参考中山市民政局导读：https://www.zs.gov.cn/mzj/zdlyxxgk/shjzhfl/content/post_2517785.html
