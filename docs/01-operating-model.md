# 敏之诗第一阶段组织架构

## 阶段定位

第一阶段不是扩张，而是验证：用最小规模跑通“公开说明、申请、核验、发放、记录、复盘”的闭环。

所有角色和流程必须服从 `docs/00-project-rules.md`。如果执行便利和项目铁律冲突，优先遵守项目铁律。

## 最小角色

- 发起人：确定预算、维护公开信息、做最终资助决定。
- 项目记录员：维护 GitHub、月度记录、申请状态表。初期可由发起人兼任。
- 申请沟通员：收集申请材料、保护隐私、与申请人确认信息。初期可由发起人兼任。
- 外部观察者：1-2 位可信朋友或文学界同伴，定期查看流程是否公平、是否有隐私风险。

## 第一阶段工作流

1. 公开项目说明和申请边界。
2. 发布第一条短视频，收集线索和反馈。
3. 建立申请表单或邮箱入口。
4. 对申请人做最小必要核验：发表记录、身份自述、困难情况说明。
5. 每月选择 1 位资助对象。
6. 完成转账后记录：月份、金额、是否匿名、简要说明。
7. 月末复盘：申请数量、处理情况、问题、下月调整。

## 信息公开边界

- 可公开：规则、流程、总支出、月度进度、匿名案例。
- 谨慎公开：作品链接、申请人署名、城市、职业。
- 不公开：身份证件、具体住址、银行卡、详细病史、家庭成员隐私、未经同意的聊天记录。
