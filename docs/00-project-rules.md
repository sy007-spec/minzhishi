# 敏之诗工作规则与项目铁律

这份文件是敏之诗的底线文件。后续任何申请规则、协议签署、社媒表达、资金记录、志愿者协作和公开说明，都应优先服从这里的原则。

## 一、项目定位铁律

1. 敏之诗第一阶段是个人小额资助尝试，不是公开募捐项目。
2. 第一阶段暂不接受公众捐款、代收款或众筹资金。
3. 不把项目包装成成熟公益机构，不使用超出当前能力的承诺。
4. 不承诺解决诗人的根本困境，只承认这是有限、具体、可持续尝试。
5. 项目的扩大必须慢于规则、协议、记录和合规能力的成熟。

## 二、资助原则铁律

1. 小额优先：先做每月 300 元人民币这样发起人能长期承担的支持。
2. 真实优先：申请人必须是真实写作者，且有可核验的诗歌发表记录。
3. 自愿优先：不替任何人申请，不在未经本人同意的情况下公开其困境。
4. 当月能力优先：没有预算时不硬撑，不借公益名义制造债务或压力。
5. 不搞排名：不把诗人按“更穷”“更惨”“更值得”公开比较。
6. 不制造依附：资助是支持，不是控制；不要求受资助者宣传、站台、写感谢文、提交作品或提供任何对价。

## 三、资助期限铁律

1. 第一阶段原则上“半年一签”，单期资助期限一般为 6 个月。
2. 标准支持金额为每月 300 元人民币，除非协议另有明确约定。
3. 每期资助到期自然结束，不自动续期。
4. 续签必须重新确认预算、受资助人意愿、基本资格和项目执行能力。
5. 续签不是承诺，也不是受资助人的既得权利；不得在公开表达中暗示长期固定供养。
6. 如发起人预算不足、规则调整、合规风险上升或双方信任基础消失，可以按协议暂停、提前终止或不再续签。
7. 任何期限、金额、暂停、终止和续签，都必须有书面记录。

## 四、协议铁律

1. 每一位受资助人获得第一笔款项前，原则上应签署小额支持协议。
2. 协议必须写明：双方身份、资助金额、资助期限、支付方式、无对价、无附带义务、无经济利益安排、隐私保护、提前终止、争议处理。
3. 协议必须确认：双方不存在劳动、雇佣、委托、投资、借贷、担保、买卖、出版代理、版权转让或商业合作关系。
4. 协议必须确认：资助款来源合法合规，由发起人个人资金支付；受资助人收到款项后的使用由其自行决定并自行保证合法合规。
5. 协议不得要求受资助人以作品、署名、宣传、社媒发布、背书、合作机会或其他权益作为交换。
6. 协议可以电子签署，但签署记录、版本和日期必须留存。
7. 协议模板见 `docs/templates/poet-support-agreement.md`，使用前应按具体情况填写并保留最终签署版。

## 五、公开透明铁律

1. 必须公开：项目规则、申请流程、月度进展、总支出、规则变更记录。
2. 可以公开：匿名案例、资助月份、金额、公开作品链接。
3. 谨慎公开：姓名、笔名、城市、职业、作品链接、申请理由。
4. 禁止公开：身份证件、手机号、住址、银行卡、病历、收入凭证原件、家庭成员隐私、未经同意的聊天记录、协议签署版全文。
5. 每次公开记录都要问一句：这条信息对公共监督是否必要？如果不是，就不公开。

## 六、隐私与尊严铁律

1. 不把任何申请人的困境做成传播素材。
2. 不拍摄、不转述、不截图展示对方的脆弱时刻。
3. 不使用“拯救”“施舍”“救助可怜诗人”等居高临下表达。
4. 允许申请人匿名，允许申请人在任何阶段撤回公开授权。
5. 沟通中默认对方是有尊严的合作者，而不是被审查对象。
6. 收集个人信息必须遵守最小必要原则，只为申请、核验、协议履行和记录留存使用。

## 七、申请与核验铁律

1. 只收集完成判断所必需的信息。
2. 核验重点是发表记录、本人意愿和基本困难说明，不做羞辱式证明。
3. 对无法判断的申请，宁可暂缓，不做草率结论。
4. 申请材料仅用于本项目判断和协议履行，不挪作社媒内容、研究素材或他用。
5. 有利益关系时必须记录并回避：亲友、合作伙伴、雇佣关系、商业往来等。
6. 未成年人原则上不纳入第一阶段资助范围；如未来涉及，必须另建监护人同意和未成年人信息保护规则。

## 八、资金铁律

1. 第一阶段资金来自发起人个人预算。
2. 每笔支出必须记录：日期、金额、用途、对应协议期、是否匿名、记录人。
3. 不以项目名义借钱，不做保本、返利、投资、销售、代理、出版承诺等行为。
4. 如未来接受外部资金，必须先补齐合规、财务、公示和责任机制，再开始收款。
5. 任何资金记录都要能让普通旁观者看懂。
6. 不代受资助人决定资金用途；受资助人应自行确保资金使用合法合规。

## 九、社媒表达铁律

1. 先说清楚项目边界，再表达愿望。
2. 不用煽动性标题，不制造对立，不消费贫困。
3. 不承诺“马上帮助所有人”，不暗示“转发就一定获得资助”。
4. 所有发布内容都必须包含：小额、个人出资、暂不接受公众捐款、保护隐私。
5. 评论区和私信回复保持克制，不公开争辩申请人的真实性。
6. 收到质疑时优先补充规则和记录，而不是要求别人相信发起人。

## 十、组织协作铁律

1. 初期角色可以兼任，但责任必须写清。
2. 任何新增协作者必须先同意本文件和项目协议边界。
3. 协作者不得私自保存、转发、讨论申请人的敏感材料。
4. 外部观察者只监督流程，不替项目索取隐私。
5. 所有规则变更必须留下日期和理由。

## 十一、纠错铁律

1. 发现规则不清，公开修正。
2. 发现误判，公开说明可公开部分，并私下向当事人道歉。
3. 发现隐私风险，先下架或隐藏相关内容，再复盘。
4. 发现项目能力不足，可以暂停；暂停不是失败，失控扩张才是风险。
5. 每月至少做一次复盘：哪些做到，哪些没做到，下月怎么改。

## 十二、第一阶段不做清单

1. 不接受公众捐款。
2. 不公开申请人敏感隐私。
3. 不做悲情案例营销。
4. 不以资助换宣传、换作品、换站台。
5. 不替申请人编写困难叙事。
6. 不承诺长期固定资助，除非当期协议和公开记录中明确说明。
7. 不让项目规模超过记录、核验、协议管理和沟通能力。

## 一句话总则

把诗人当作有尊严的人，把钱当作需要被记录的责任，把协议当作保护双方边界的方法，把公开当作接受监督的方式，而不是获取信任的表演。
