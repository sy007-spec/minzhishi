# 敏之诗

敏之诗是一个从个人能力出发的小额诗人支持项目。

第一阶段目标很小：尝试每月支持一位可能正遇到经济困难、且有可核验诗歌发表记录的诗人，每人每月 300 元人民币。项目先由个人出资试运行，暂不接受公众捐款。

## 为什么开始

有些诗人仍在写作，也仍在承受现实生活的压力。300 元解决不了根本问题，但它可以是一点缓冲、一点确认，也可以成为一套更长期互助机制的起点。

## 第一阶段原则

- 小额：先做自己能持续承担的事。
- 公开：公开规则、流程、月度进展和资金去向。
- 克制：不消费困境，不公开申请人的敏感隐私。
- 可修正：标准、流程和组织方式都允许在实践中改进。

完整工作底线见：`docs/00-project-rules.md`。后续所有申请、公开、社媒发布和协作流程，都应优先服从这份“工作规则与项目铁律”。

## 暂定申请条件

- 申请人是诗歌写作者。
- 有诗歌作品发表于正式刊物或可信公开平台。
- 正在经历现实经济困难。
- 本人自愿申请，并同意必要的信息核验。

## 运维方式

所有需要程序脚本运维的动作统一走根目录 `ops.py`：

- 安装外部依赖：`python ops.py install`
- 检查视频工程：`python ops.py check`
- 渲染视频：`python ops.py render`
- 查看视频元数据：`python ops.py probe`
- 抽取关键帧：`python ops.py frames`
- 启动预览：`python ops.py preview`

Git 只保留源码、规则、文案、配置和项目自有资产；`node_modules/`、渲染视频、抽帧图片、缓存、日志等工程性外部可获取或可再生成内容不纳入版本管理。

## 重要说明

本项目当前是个人小额资助尝试，不是公开募捐项目。后续如涉及接受外部资金、公益组织合作、税务或合规事项，需要另行建立合规机制。
